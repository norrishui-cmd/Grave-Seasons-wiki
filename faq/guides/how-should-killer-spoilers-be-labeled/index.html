How should Grave Seasons killer spoilers be labeled?

Killer-specific names, victims, clues, protection steps, and endings should sit behind explicit campaign spoiler warnings.

Quick answer

  • Category: Guides
  • Evidence: current first-party material
  • Answer status: concrete and source-backed
  • Pre-release facts may still change

Confirmed detail

Stable character identity and universal mechanics can remain visible, but one campaign's culprit must never be presented as the universal answer.

How to use this answer

This answer separates a current confirmed fact from values that official material has not supplied. It can be used for planning, platform comparison, spoiler-safe browsing, or deciding which deeper guide to open without treating speculation as game data.

Verification boundary

Exact schedules, prices, rewards, routes, item statistics, campaign identities, performance values, and launch-day behavior are included only when a primary source or repeatable retail-build test answers this specific question.

Source policy

The answer was reviewed against an official Grave Seasons source. New information updates this URL in place so players and search engines do not have to choose between conflicting duplicates.
