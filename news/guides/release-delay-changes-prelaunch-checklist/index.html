Guide News · July 31, 2026

Fall 2026 Delay Changes the Prelaunch Guide Checklist

The former August 14 date is obsolete, so current preparation guides should use the Fall 2026 window and wait for a replacement day.

Update snapshot

  • Topic: Guide Index
  • Status: verified official information
  • Reviewed: July 31, 2026
  • Pre-release details may still change

What the official update confirms

The June developer update moved the full game to Fall 2026 so the team could prioritize polish across every announced platform. It also cancelled the planned June 15 public demo. A reliable prelaunch checklist now centers on wishlisting, platform confirmation, language support, and official date monitoring—not an expired countdown.

What this changes for players

This matters because old launch-day plans, preload assumptions, and demo walkthroughs can mislead players. Guide pages now separate current official status from historical announcements and preserve the old date only as context.

What is not confirmed

No exact replacement day, preload window, launch hour, price, or download size has been published. Those fields remain absent until an official storefront or developer post supplies them.

Primary source

This update was checked against the official Grave Seasons developer or Steam publication. If a newer first-party announcement changes the fact, this canonical page will be revised rather than duplicated.
